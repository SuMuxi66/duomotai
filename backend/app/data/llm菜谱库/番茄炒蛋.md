# 番茄炒蛋的做法

预估烹饪难度：★☆☆

## 必备原料和工具

- 番茄
- 鸡蛋
- 食用油
- 盐
- 糖
- 葱花
- 炒锅
- 碗筷

## 计算

每份：

- 番茄 2 个（约 300g）
- 鸡蛋 3 个
- 食用油 20-30ml
- 盐 适量（蛋液中加少许，调味时加少许）
- 糖 5g（约半勺）
- 葱花 少许

## 操作

- 鸡蛋打入碗中，加入少许盐搅打均匀；番茄洗净切成块状。
- 热锅倒入适量食用油，油热后倒入蛋液，中火翻炒至凝固成型，盛出备用。
- 锅中再加少许油，放入番茄块，中火翻炒 2-3 分钟直至炒出红油汁水。
- 向锅中加入糖和适量盐调味，翻炒均匀。
- 倒回之前炒好的鸡蛋，快速翻匀使鸡蛋吸收汤汁，大火收汁约 30 秒。
- 撒上葱花，关火出锅装盘。

## 附加内容

- 喜欢汤汁拌饭的，可在炒番茄时加少许清水焖煮片刻。
