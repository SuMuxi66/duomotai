# 番茄炒鸡蛋的做法

预估烹饪难度：★☆☆

## 必备原料和工具

- 成熟番茄
- 新鲜鸡蛋
- 食用油
- 盐、白糖
- 葱花（可选）
- 清水或料酒（可选）
- 炒锅、铲子、碗、筷子

## 计算

每份（2 人量）：

- 番茄 2 个（约 300g）
- 鸡蛋 3 个
- 食用油 20-30ml
- 盐 适量（分两次使用）
- 白糖 5-10g
- 清水 15ml（加入蛋液中，可选）
- 葱花 少许

## 操作

- 番茄洗净后切成滚刀块备用。
- 鸡蛋打入碗中，加入少许盐和 15ml 清水（或 2 滴料酒），用筷子充分打散至蛋液表面起泡沫。
- 锅中倒入适量油烧热，倒入蛋液，待蛋液稍微凝固时用铲子轻轻推动，炒至七成熟形成大块嫩蛋后盛出备用。
- 锅中再倒入少许油，放入葱花爆香（若不喜葱可省略），加入番茄块中火翻炒。
- 待番茄开始出汁时，加入白糖和适量盐调味，继续翻炒至汤汁略微浓稠。
- 将炒好的鸡蛋倒回锅中，与番茄一起中火翻炒均匀，让鸡蛋充分吸收番茄汁，约 30 秒即可关火装盘。

## 小贴士

- 蛋液中加入少许清水或料酒，可使炒出的鸡蛋更加蓬松鲜嫩。
- 白糖能有效中和番茄的酸味，使口感更圆润，不建议省略。
- 喜欢汤汁拌饭的，可在炒番茄时稍加一点水延长炖煮时间；喜欢干爽口感的则快速翻炒出锅。
- 可根据个人口味添加蒜末、生抽、蚝油提鲜，或加入青椒丁、木耳丝等辅料丰富口感。
