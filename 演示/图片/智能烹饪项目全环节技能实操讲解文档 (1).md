## 模块一：语料收集与菜谱匹配

数据是整个智能烹饪项目的核心底层支撑，我项目所用到的所有菜谱数据，均来源于开源公益项目How To Cook官方公开数据集，整体一共收录了364道完整菜谱。数据覆盖家常菜、快手菜、川湘风味菜等多种主流菜品类型，每一道菜谱都完整包含食材清单、烹饪步骤、制作难度、热量参考等关键信息，数据来源真实可靠，非常贴合智能烹饪场景的开发需求。虽然原始的Markdown菜谱文件内容完整，但属于非结构化文本，整体字段杂乱、格式不统一，程序无法直接识别和检索调用。因此我对原始语料进行了标准化结构化处理，让零散的文本数据转化为程序可高效识别、可精准匹配的结构化数据。

### 【演示点1】语料结构化数据封装

想要实现菜谱的智能检索与精准匹配，首先需要把杂乱无序的原始文本，转化为程序能够稳定识别、统一调用的标准化数据。我自定义了专属的菜谱数据实体类，对菜品名称、所需食材、菜品分类、匹配分数等核心字段进行统一封装和规整。同时结合正则表达式精准抓取菜谱中的关键信息，搭配内存缓存机制，避免程序重复读取本地文件，有效提升整体的数据加载效率和菜谱检索速度。

## 模块二：步骤式引导系统

通过检索功能获取到目标菜谱之后，单纯的静态文字菜谱，无法实现循序渐进的智能烹饪教学。为此我搭建了完整的步骤引导调度框架，通过后端状态机精准管控整体烹饪进度，搭配前端可视化进度UI，实现全程标准化、连贯化的分步语音教学引导。

### 【演示点1】StepGuide 前后端一体化联动烹饪步骤引导体系

## 模块三：语音交互支持

在实际的烹饪过程中，用户双手基本处于被占用的状态，触控操作非常不便。基于这一场景痛点，我搭建了全套完善的语音交互体系，包含精准语音唤醒、流式实时识别、全程语音打断三大核心能力，实现全程免触摸语音操控，完美适配厨房实操场景。

### 【演示点1\+2】全链路语音输入：两级唤醒 \+ 流式实时识别（完整联动逻辑）

整套语音交互的输入链路是一套完整的联动逻辑，我是按照「先精准唤醒激活设备、再实时识别语音内容」的流程搭建的，全程无缝衔接。首先要解决的是厨房环境下的无效触发问题，所以我设计了噪音过滤加关键词匹配的两级唤醒机制，作为整个语音交互的前置入口，专门用来精准判定有效人声，过滤环境噪音，从源头避免误唤醒、漏唤醒，为后续语音识别提供可靠的启动条件。

#### 核心实操代码

```python
class WakeWordDetector:
    def __init__(self):
        self.vad_threshold = 30
        self.wake_words = ["小云小云", "小云"]
        self.audio_buffer = bytearray()
    def calculate_volume(self, pcm_data):
        rms = np.sqrt(np.mean(np.frombuffer(pcm_data, dtype=np.int16).astype(float)**2))
        return float(rms)
    def add_audio(self, pcm_data):
        if self.calculate_volume(pcm_data) < self.vad_threshold:
            return False
        self.audio_buffer.extend(pcm_data)
    def check_wake_word(self, text):
        text = text.replace(" ", "").replace("。", "").replace("，", "")
        return any(w in text for w in self.wake_words)
```

#### 实操核心讲解

系统运行时，会实时计算音频音量，自动过滤掉厨房环境里的风声、炒菜声等无效噪音，只有检测到符合音量阈值的有效人声时，才会收录音频数据并清洗文本、匹配预设唤醒词。一旦唤醒校验成功，就会立刻激活后续的语音识别通道，正式开启语音交互流程，整套前置唤醒逻辑，是后续流式识别能够稳定运行的基础保障。

当设备被唤醒、交互通道成功激活后，系统不会采用传统等待用户说完再识别的卡顿模式，而是直接启动分片流式语音识别逻辑，对唤醒后收录的完整音频流进行实时分片解析。通过前后衔接的整套逻辑，实现「唤醒激活、即刻识别」的流畅体验，彻底解决传统语音交互延迟高、体验生硬的问题，贴合厨房边操作边说话的使用场景。

```python
class InterruptHandler:
    def __init__(self, state):
        self.state = state
    async def handle_interrupt(self):
        self.state.interrupted = True
        if self.state.current_task and not self.state.current_task.done():
            self.state.current_task.cancel()
```

##### 核心实操代码

```typescript
// 多级图像压缩：等比例缩放 + JPEG画质压缩
export async function compressImage(
  canvas: HTMLCanvasElement,
  maxWidth: number,
  quality: number
): Promise<string> {
  let { width, height } = canvas;

  // 第一步：等比例分辨率缩放
  if (width > maxWidth) {
    const scale = maxWidth / width;
    width = Math.round(width * scale);
    height = Math.round(height * scale);
  }

  // 创建缩放画布
  const resizeCanvas = document.createElement("canvas");
  resizeCanvas.width = width;
  resizeCanvas.height = height;
  const ctx = resizeCanvas.getContext("2d");
  ctx?.drawImage(canvas, 0, 0, width, height);

  // 第二步：JPEG画质压缩输出base64
  return resizeCanvas.toDataURL("image/jpeg", quality);
}
```

##### 实操核心讲解

系统会先对画面进行等比例尺寸缩放，再完成JPEG画质压缩，最大程度减小图片传输体积。同时配置了完善的容错机制，如果压缩过程出现异常，系统会自动返回原始画面，保证图像数据始终可用，兼顾了交互速度与画面识别准确性。

```python
import asyncio
from typing import List, Callable

# 通用可扩展事件轮询核心框架
class EventPoller:
    def __init__(self, poll_interval: float = 0.5):
        self.poll_interval = poll_interval
        self._event_sources: List[Callable] = []
        self._on_event_callbacks: List[Callable] = []
        self._running = False

    # 插件式注册检测源
    def add_event_source(self, source: Callable):
        self._event_sources.append(source)

    # 注册事件回调业务逻辑
    def on_event(self, callback: Callable):
        self._on_event_callbacks.append(callback)

    # 启动后台持续轮询
    async def start(self):
        self._running = True
        while self._running:
            await self._poll_once()
            await asyncio.sleep(self.poll_interval)

    # 单次轮询检测 + 幂等过滤
    async def _poll_once(self):
        for source in self._event_sources:
            event = source()
            # 过滤已处理事件，防止重复触发
            if event and not event.handled:
                await self._handle_event(event)

    # 统一事件处理，兼容同步/异步回调
    async def _handle_event(self, event):
        event.handled = True
        for callback in self._on_event_callbacks:
            if asyncio.iscoroutinefunction(callback):
                await callback(event)
            else:
                callback(event)
```

```python
            r"(?P<num>[零一二三四五六七八九十\d]+)?\s*(?P<unit>小时|分钟|秒)",

            elif cn_str[0] == "十":

            elif unit == "秒":
```

```python
# 定时器归零、单删、批量清空核心方法
def cancel_timer(self, timer_id: str) -> bool:
    """单个定时器归零删除，终止对应后台协程"""
    if timer_id in self._timers:
        timer = self._timers[timer_id]
        # 终止后台异步任务，防止残留弹窗
        if timer._task and not timer._task.done():
            timer._task.cancel()
        del self._timers[timer_id]
        return True
    return False

def cancel_all_timers(self, category=None) -> int:
    """批量清空定时器列表，全局归零，清空所有残留任务"""
    cancelled_count = 0
    # 副本遍历，规避遍历删除报错
    for timer_id in list(self._timers.keys()):
        timer = self._timers.get(timer_id)
        if timer and (category is None or timer.category == category):
            self.cancel_timer(timer_id)
            cancelled_count += 1
    return cancelled_count
```

```python
import serial
import serial.tools.list_ports
import platform
import time
from threading import Thread, Lock

class MLX90640Reader:
    def __init__(self):
        self.ser = None
        self.buffer = bytearray()
        self.running = False
        self.lock = Lock()
        self.temp_data = {"target": 0.0, "average": 0.0}

    # 跨平台适配 + 设备自动握手识别
    def auto_connect(self) -> bool:
        for port in serial.tools.list_ports.comports():
            # 适配Windows/Linux双系统端口规则
            if platform.system() == "Windows":
                if not (port.device.upper().startswith("COM") and port.device[3:].isdigit()):
                    continue
            else:
                if not any(x in port.device for x in ("/dev/ttyUSB", "/dev/ttyACM")):
                    continue
            # 自定义握手指令 + 帧头校验筛选设备
            try:
                ser = serial.Serial(port.device, 115200, timeout=1)
                ser.write(bytes([0xA5, 0x35, 0x02, 0xDC]))
                time.sleep(0.5)
                if b"\x5A\x5A" in ser.read(ser.in_waiting):
                    self.ser = ser
                    return True
            except:
                continue
        return False

    # 滑窗帧同步 + 高精度温度解析
    def _parse_frame(self):
        if not self.ser or not self.ser.in_waiting:
            return
        self.buffer += self.ser.read(self.ser.in_waiting)
        # 截取完整数据帧（固定1544字节）
        while len(self.buffer) >= 1544:
            idx = self.buffer.find(b"\x5A\x5A")
            if idx == -1:
                self.buffer = self.buffer[-2:]
                break
            frame = self.buffer[idx:idx+1544]
```
