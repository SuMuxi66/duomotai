# 硬件连接 (STM32F103C8T6)

## HX711模块 → STM32
| HX711 | STM32 |
|-------|-------|
| VCC | 3.3V 或 5V |
| GND | GND |
| SCK | PA1 |
| DT | PA0 |

## STM32 → USB转TTL模块
| STM32 | USB转TTL |
|-------|----------|
| TX (PA9) | RX |
| RX (PA10) | TX |
| GND | GND |

## 编译步骤

1. 使用 STM32CubeMX 创建工程
2. 配置 PA0 为输入模式 (DT)，PA1 为输出模式 (SCK)
3. 配置 USART1 波特率 9600
4. 添加以上文件到工程
5. 编译并烧录到STM32

## 串口输出格式

STM32会每秒发送一次数据，格式为：
```
W=123.45
```

其中 123.45 是重量值（克）。
