# 电磁阀控制系统规格文档

## 1. 系统概述

通过电脑USB转TTL模块连接单片机，单片机控制继电器进而控制电磁阀的开关。

## 2. 硬件连接

```
电脑USB → USB转TTL模块 → 单片机TX/RX
                                    ↓
                              单片机GPIO引脚
                                    ↓
                                继电器模块
                                    ↓
                                电磁阀
```

### 接线定义
- USB转TTL RX → 单片机 TX
- USB转TTL TX → 单片机 RX
- 单片机 GPIO → 继电器信号引脚
- 继电器控制电磁阀通断

## 3. 通信协议

### 串口参数
- 波特率：9600
- 数据位：8
- 停止位：1
- 无校验

### 指令格式（ASCII字符串）
| 指令 | 功能 | 说明 |
|------|------|------|
| `ON\r\n` | 打开电磁阀 | 继电器吸合 |
| `OFF\r\n` | 关闭电磁阀 | 继电器释放 |
| `STATUS\r\n` | 查询状态 | 返回当前电磁阀状态 |
| `PULSE,XXX\r\n` | 脉冲控制 | 打开XXX毫秒后自动关闭 |

### 响应格式
| 响应 | 说明 |
|------|------|
| `OK` | 命令执行成功 |
| `ERR` | 命令执行失败 |
| `ON` | 电磁阀当前打开 |
| `OFF` | 电磁阀当前关闭 |

## 4. 单片机程序功能

- 监听串口接收指令
- 解析指令并控制GPIO输出
- 向串口返回执行结果
- 支持脉冲模式（定时自动关闭）

## 5. PC端控制程序功能

- 串口自动检测和连接
- 命令行界面交互
- 支持脚本化控制
- 实时显示电磁阀状态

## 6. 技术选型

- 单片机程序：Arduino/C（兼容UNO/Nano/ESP32等）
- PC端程序：Python 3.x + pyserial
